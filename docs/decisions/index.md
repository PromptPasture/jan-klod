- [2026-09-13 — REST concurrency and the `!Send` session](2026-09-13-rest-concurrency-and-the-send-session/Handoff.md) — adopt `axum` + `tokio` for the inbound HTTP surface, superseding `mcp.rs`'s rejection of it on three measured grounds: the marginal cost is **16 packages** (not 53 — 36 are already in the lock via `wasmtime-wasi`), the tree passes `deny.toml` **unmodified** where Tauri needed eleven exceptions, and the `!Send` premise is **not** wasmtime but two local traits missing a `Send` supertrait — compiler-verified, with no production type failing the check. Fixes #43's blocker (a real `TcpStream` has `try_clone` + `set_read_timeout`) and REST's one-request-at-a-time limit, which are independent problems that looked like one
